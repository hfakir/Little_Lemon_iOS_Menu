# Little Lemon Menu App 🍋

A clean iOS application built with SwiftUI, featuring a structured restaurant menu layout with categorized sections for Food and Drinks.

## Features
- **Categorized Sections:** Clean separation between Food items and Drink items.
- **Custom UI Components:** Grid-based layout optimized for modern iOS displays.
- **Filter Options:** Interactive filtering functionality to sort menu items seamlessly.

## Tech Stack
- **SwiftUI**
- **Swift**
- **Xcode**
